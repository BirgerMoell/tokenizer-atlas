03 / WHAT “SUPPORT” MEANS

Three different claims

ENCODABLE

Can represent the text

Byte-level encoding or byte fallback can encode unfamiliar scripts without unknown tokens. This is a technical guarantee, not efficient segmentation.

EFFICIENT

Uses a reasonable token budget

Requires held-out measurement for each language and script. Georgian's v1→v2 change shows why broad fallback alone is insufficient.

MODEL CAPABILITY

Can perform tasks well

Requires language-specific training and downstream evaluation. A tokenizer benchmark cannot establish model understanding.

04 / DESIGN DECISIONS

What to improve next

01

Make the language inventory canonical

Use the current 36-language catalogue and explicit script variants. Older 38-language lists include languages dropped from the current tokenizer training scope. Version the list with each run.

02

Protect the long tail during tokenizer training

Set minimum sampling by priority language and script; include a wider multilingual reserve. Track the worst-language token penalty, not just the mean. Swiss AI's parity-aware BPE experiments are a useful comparison.

03

Choose vocabulary size by end-to-end cost

OpenEuroLLM v2 256k uses fewer tokens than v2 128k on its benchmark, but doubles the nominal vocabulary. Measure prefill, decode, memory and output-head cost at target model sizes before freezing a choice.

04

Run one shared held-out suite

Evaluate identical text across priority languages, additional world scripts, code, math, chat and PDFs. Publish per-language results, round-trip errors, fallback rates, and pinned tokenizer revisions.

05 / PROVENANCE

Read the numbers carefully

The main comparison reproduces values from the OpenEuroLLM 256k v2 model card. Its overall column combines a five-domain suite; it is not a universal ranking. The table has not been independently rerun in this repository.

The Swiss AI preliminary v2 study uses different data and metrics. Its approximately 200k-token candidate reports 4.245 European bytes/token versus 3.865 for Apertus v1, with worst-language penalty 3.61× versus 14.70× English. Those numbers are contextual evidence, not rows in the shared chart.
